# Bridge++

Windows 桌面 Agent 开发工作台。把 Qoder CN、WorkBuddy 等模型源接到 DeepSeek Harness（DSH）、Kimi Code、Codex CLI、Claude Code 等开发环境里，在一个窗口里管理项目、会话和模型。

> 这是个人维护的非官方项目，与 Qoder、腾讯、DeepSeek、月之暗面、OpenAI、Google 没有关联。

## 功能

- **一个窗口用多个环境**：DSH、Kimi Code、Codex CLI、Claude Code、Antigravity，会话按文件夹分组，工具、技能、MCP 和子代理都留在各环境自己的原生流程里。
- **模型和环境自由搭配**：Qoder CN、WorkBuddy 的模型可以在 DSH、Kimi Code、Codex CLI、Claude Code 里用，上下文窗口和思考强度按来源声明的能力选择。两个源的模型都走上游的原生函数调用，工具参数由上游结构化给出，长参数和一次多个调用不会被写坏；同一个任务的多步工具调用在上游保持同一个会话，缓存命中更高。
- **价格、余额和用量**：模型菜单里每个模型都标出当前的积分倍率，错峰折扣、限时免费和 DeepSeek 峰谷价会按当前时间计算。两个模型源的积分余额显示在顶栏的会话标题旁边，点一下重新读取。打开模型菜单或一轮对话结束时，超过 5 分钟没更新的价格和余额会重新读取。每轮结束时显示这个会话累计的请求数和输入、输出 tokens，Qoder 的模型还会显示实际扣的积分。
- **Claude Code 只当工具执行器**：只用上面这些模型源的模型，不登录、不连接 Anthropic，也不读写你本机 Claude 的配置和数据。“自动审查”模式下由 Bridge++ 用同一个模型代为审查，拿不准的操作交给你确认。
- **Codex 用模型源时与你自己的 Codex 分开**：这类会话用 Bridge++ 自己的 Codex 配置目录，不带你的 Codex 登录、已批准的命令、历史和电脑/浏览器控制插件，只保留文档类插件和 node_repl；沙箱用不需要管理员权限的 unelevated 模式。
- **长期要求**：你在对话里提出的长期要求（比如“以后都先说结论”）会被自动识别并记在 Bridge++ 自己的 AGENTS.md 里，对话中提示，可以一键撤销；之后所有环境和模型都会看到。可以在“设置 › 长期要求”里查看、编辑、关闭自动记录，或换识别用的模型（默认用 DeepSeek Flash）。
- **运行中插话**：任务运行时可以直接发消息。DSH 和网关模型的 Codex 会把消息插进正在运行的这一轮，其他环境排队到本轮结束后自动发出。
- **对外接口**：把模型源变成本机 OpenAI 兼容接口，一键接入 DSH、Kimi Code、Codex CLI，也可以给其他 Agent 用，支持开机在后台运行。
- **环境管理**：首次启动有引导，之后可以在设置里检查更新和更新环境。没配置好的环境不会出现在可选项里，只要有一个能用就能开始。
- **权限模式**：按环境选择授权方式，比如 DSH 的仅可查看、工作区内修改、自动审查、完全权限。
- **看得见的报错**：上游的实际报错、限速重置时间和中断原因都显示在对话里。
- **联网搜索**：DSH 环境可以直接用 Qoder CN、WorkBuddy 自带的搜索，不需要另外的 API key。
- **读起来方便**：LaTeX 公式直接渲染；连续的工具调用、思考和已批准的授权折叠成一行；回答里的文件链接点击就能预览，右键可以在资源管理器中显示；网页链接点击用浏览器打开，右键可以复制。
- **图片和媒体**：上游支持时可以在输入框发送图片，模型输出的图片也会显示。
- **导出反馈**：会话菜单里的“导出反馈…”把这个会话的报错和纠正记录打包成一个 zip，方便发给开发者定位问题。默认不含对话正文和工具参数；密钥、用户目录、项目和数据目录的路径、邮箱和手机号会被替换。
- **更新提醒**：每天第一次启动时检查新版本，有新版本才在左下角提示；也可以在“设置 › 关于”手动检查，或打开“自动下载更新包”。

## 安装

1. 到 [Releases](../../releases/latest) 下载 `Bridge++-Setup-<版本>.exe`，双击运行。不需要管理员权限，装好后自动打开。
2. 安装包没有代码签名，Windows 可能提示“已保护你的电脑”：点“更多信息”，再点“仍要运行”。

系统要求：Windows 10 或 11，64 位。

## 首次使用

首次启动会打开引导，分三步：

1. **开发环境**：至少准备一个。Kimi Code 已内置，其他环境可以在引导里下载或指定路径。Codex CLI 和 Antigravity 需要能访问 OpenAI、Google 的网络和账号，没有也不影响使用其他环境。
2. **模型源**：安装包不附带任何模型源。在引导里点“下载组件”，组件会从 npm 下载到你的电脑；账号用官方客户端登录，再点“重新检测”。

   | 模型源 | 需要 |
   |---|---|
   | Qoder CN | [Qoder CN](https://qoder.cn/) 账号，用官方客户端或 CLI 登录 |
   | WorkBuddy | [WorkBuddy](https://www.workbuddy.cn/) 账号，用官方桌面端登录 |
   | Antigravity · Gemini | 已登录的 Antigravity，由它原生运行 |

3. **工作文件夹**：选一个项目文件夹。

## 给其他 Agent 用

在“设置 › 对外接口”启动接口，在“接入到”选择目标 Agent，再点底部按钮完成配置。接口只监听 `127.0.0.1`，需要随机生成的密钥。接入 DSH 时 DSH 开着或关着都可以，运行中的 DSH 几秒内自动加载。

## 从源码运行

需要 Node.js 22.19 或更高版本（打包固定用 `.node-version` 里的版本），并且能访问 npm 官方仓库。`npm ci` 时 Qoder SDK 的安装脚本还要从 `static.qoder.com.cn` 下载官方运行时。

```bash
npm ci
npm run build
npm start
```

运行测试：

```bash
npm test
```

```bash
npm run test:bridges
```

打包安装程序：

```bash
npm run package:installer
```

## 关闭窗口和卸载

- 对外接口是独立的后台程序，关掉 Bridge++ 窗口后继续运行，要停止请在“设置 › 对外接口”操作。
- 升级时安装程序会先让运行中的接口退出，装完自动恢复。
- 卸载时会停止接口、删除开机启动任务，并询问是否同时删除数据（默认保留）。
- 卸载不会改动 DSH、Kimi Code、Codex CLI 的配置。想把接口从这些环境里移除，先在“设置 › 对外接口”点“断开”。

## 数据和隐私

- 项目、会话和设置保存在本机 `%APPDATA%\AgentWorkbench`。
- Bridge++ 本身不收集数据。对话内容只发给你选择的模型服务。
- 模型源的登录信息由各自的官方客户端管理，Bridge++ 只在本机读取，用来发起你的请求和查询积分余额。
- 检查更新：每天第一次启动时向 `api.github.com` 查询本仓库的最新 Release，不附带任何个人数据；更新包只从 GitHub 下载，发布提供了 SHA-256 时会核对。
- 导出反馈的 zip 只保存在你的电脑上，不会自动上传。
- 长期要求保存在本机 `%APPDATA%\AgentWorkbench\workspace\AGENTS.md`。自动识别会把你发的每条消息作为一次辅助请求发给识别模型，按模型的积分倍率计费：默认是会话所用模型源自己的 DeepSeek Flash，所以消息不会多发给别的服务；会话用原生模型（不经过 Bridge++ 模型源）时交给 WorkBuddy 的 DeepSeek Flash。识别模型用不了时会改用另一个模型源的 DeepSeek Flash。不想要可以在“设置 › 长期要求”里关掉。
- 对外接口的固定端口（8646、8647）只监听本机。同一台电脑上如果有其他账号先占用了端口，接入的客户端可能把密钥和请求发给对方：多人共用的电脑请留意卡片上的端口占用提示，或换一个端口。
